# Release Audit: v0.1.0

Date: 2026-08-22
Scope: Licensing, provenance, asset redistribution rights, privacy hygiene, and history-aware secret scanning for the `v0.1.0` release of `howarewoo/omp-remote`.

## Executive Summary

- **Repository License**: MIT (`Copyright (c) 2026 Adam Woo`), declared in the root `LICENSE` file and across all 10 manifests (root manifest plus 9 workspace package manifests).
- **Package Visibility**: All 10 workspace packages retain `"private": true`. No npm package publication is configured.
- **Production Dependencies**: Audited 75+ direct and transitive runtime packages across MIT, BSD-3-Clause, ISC, BlueOak-1.0.0, Apache-2.0, and MPL-2.0. All runtime dependency licenses permit redistribution under their respective terms.
- **Generated UI & Asset Provenance**: Evaluated shadcn/ui and Base UI components configured via root `components.json`, web icons (`apps/web/public/icons.svg`), application branding, and screenshots. Third-party trademarks and brand marks are qualified as nominatively referenced.
- **Third-Party Attribution & Notices**: A comprehensive third-party notice artifact (`apps/web/public/third-party-notices.txt`) is maintained under `apps/web/public/` so that Vite copies it into the production browser bundle distribution (`dist/third-party-notices.txt`). It contains the full copyright notices and MIT license texts for all 17 runtime packages redistributed in the web application (including `@base-ui/react` and `@base-ui/utils` by Material-UI SAS, `@floating-ui/*`, `@shadcn/react`, `react`, `react-dom`, `reselect`, `scheduler`, `sonner`, `use-sync-external-store`, `workbox-core`, `workbox-window`, `zod`, etc.).
- **Secret Scanning**: Full Git history scan across all refs (`gitleaks` v8.30.1, 244 commits) identified 0 real credentials. Two scanner hits were verified as synthetic Web Push test fixtures.
- **Privacy & Hygiene**: Personal checkout path in `session-header.test.tsx` neutralized to `/workspace/projects/omp-remote`. Tracked `.woostack/config.json` removed and transitioned to ignored local configuration (`.woostack/config.local.json`). Reusable agent configurations (`AGENTS.md`, `.omp/`, `.agents/`) remain tracked. Screenshots and documentation contain only synthetic demo sessions and no private machine/Tailnet details.
- **Increment Readiness & Verification**: Verified from a fresh temporary clone on parent `c3cb540` in a path containing spaces and shell metacharacters (`OMP Remote & hygiene`): frozen install passed; format check passed; lint passed (0 errors, 120 warnings, 23 infos); build passed across all 9 packages; root script tests (39/39) and Turbo test graph (15/15 tasks, including 378 session tests and 264 daemon tests) passed cleanly.
